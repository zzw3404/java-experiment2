# 应用部署与验收

## 开发测试

要求 Maven、JDK 11 或更新版本。运行 `mvn clean package`。测试在本地端口上启动 Tomcat 9，
数据库为 H2 MySQL 兼容模式，只使用 `sql/init.sql` 中的实验样例。
构建后核对 `target/trade-mis.war` 和 `target/evidence`。

## 独立环境

1. 新建专用 MySQL 数据库 `trade_mis`，字符集为 utf8mb4。在数据库内执行一次 `sql/init.sql`。
2. 设置 `TRADE_JDBC_USER`、`TRADE_JDBC_PASSWORD`、`TRADE_AUTH_PASSWORD`。非默认数据库地址另设 `TRADE_JDBC_URL`。
3. 将 `target/trade-mis.war` 部署到 Tomcat 9。用 Tomcat 标准脚本启动。
4. 浏览器打开 `http://localhost:8080/trade-mis/demo/index.html`，按登录、商品、品牌、订单、明细顺序验收。
5. 运行下面的 PowerShell 验收脚本。口令从环境变量读取，与服务端配置一致。
   `./deploy/Verify-Deployment.ps1 -BaseUrl http://localhost:8080/trade-mis`
6. 导入 `apifox/trade-mis.postman_collection.json`，填写集合变量，使用新样例数据库按顺序跑完整集合。

## 业务设计

品牌目录从品牌表左联商品表，聚合商品数。订单查询连接订单与客户，
订单明细通过订单 ID 关联商品，按成交单价计算小计。品牌和订单作为只读业务入口。
商品支持新增、编辑、单删和批删。订单已有引用的商品拒绝删除。
浏览器界面、样式和逻辑分别位于 `demo/index.html`、`demo/style.css`、`demo/app.js`。

Windows / JDK 17（Java 11 字节码）/ 嵌入式 Tomcat 9 / 隔离 H2。
独立 MySQL 部署是交付支持的运行模式，本次集成测试未使用本机 MySQL 数据。
